Tracket can work with Sprocket, a companion app that runs Claude agent workflows on tickets. Sign in to it in Settings > Sprocket: a ticket then gets an Agents button to start a workflow in its worktree, and an Agents section that follows the run (its steps, the agents at work, the notes they leave each other on the run's board, where you can post too) and lets you approve or reject what its agents ask, retry or stop it, or open it in Sprocket. The sidebar gets an Agents tab with your tickets an agent works on, and each row says when an agent needs you. Dragging tickets offers Hand to agents: start a workflow on each of them, ask an agent in words, or approve, retry or stop their runs; dropping them on the Agents tab starts each project's default workflow. A Windows notification tells you when an agent needs you, and comments posted by a workflow are marked via Sprocket. Nothing changes until you sign in.
